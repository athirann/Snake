# Jeu de Snake

Ce jeu de snakea été développé dans le cadre de la SAE lors de notre première année (2023) de BUT Informatique à l'IUT de Fontainebleau.

## Lancement du programme

### Compilation

```bash
make
```

### Lancement

#### Méthode n°1  : Compiler et lancer le programme avec Make

Utiliser la commande suivante pour compiler (si ce n'est pas déjà) fait puis lancer le sprogramme :

```bash
make run
```

## Fonctionnalités

### Fonctionnalités exigées

- Le terrain de jeu comporte des obstacles (fixes ou mobiles) que le serpent doit éviter.
- Affichage du temps (en secondes) écoulé depuis le début de la partie.
- Le déplacement du serpent s'accélère en fonction du score
- ### Fonctionnalités additionnelles
- Affichage du temps en secondes **et en minutes**
- Score
